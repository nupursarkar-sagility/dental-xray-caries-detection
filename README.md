# Dental X-ray Caries Detection using Deep Learning

This project trains CNN models (ResNet18, EfficientNet) to detect dental caries from panoramic dental X-rays.

## Project Structure
- notebooks: experimentation and analysis
- data: sample images and labels

## Models Used
- ResNet18
- EfficientNet-B1

## How to Run

1. Install dependencies
pip install -r requirements.txt

2. Open Jupyter Notebook
Start the Jupyter notebook environment.

3. Run the following notebooks
- 01_eda.ipynb – Exploratory Data Analysis
- 02_preprocessing.ipynb – Data preprocessing and preparation
- 03_training.ipynb – Model training using ResNet / EfficientNet
- 04_test.ipynb – Model testing on sample images


## Dataset

The full dataset is not included in this repository due to size constraints.  
Only sample images are provided for demonstration purposes.
